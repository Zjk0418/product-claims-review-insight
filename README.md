# 淘宝和京东评价采集

这里放了两个互不依赖的小项目：

- `taobao-tmall/`：抓淘宝、天猫的评价明细。
- `jd/`：抓京东商品的评价数和好评率。

你只需要哪个，就复制或下载哪个文件夹。两个文件夹都可以单独运行，不需要放在一起。

## 它们是怎么抓数据的？

程序会连接你电脑上真正打开的 Chrome，让 Chrome 帮忙发送请求。这样可以继续使用你在浏览器里的登录状态，不需要把 Cookie 手工复制进代码。

两个项目默认都使用 Chrome 的 `9222` 调试端口。只要不同时运行，就不会互相影响。

## 一定要有飞书吗？

不需要。

- 淘宝、天猫可以直接传商品链接或商品ID。
- 京东可以直接传 SPU 或商品链接。
- 只有想从飞书批量读取商品，或者把结果写回飞书时，才需要配置飞书。

具体命令请看：

- `taobao-tmall/README.md`
- `jd/README.md`

程序生成的结果、浏览器登录资料和断点都放在各自项目的 `runtime/` 中，不会共用。
